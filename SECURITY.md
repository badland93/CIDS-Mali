# Security Policy

## Overview

CIDS-Mali Platform is a secure student identity management system developed for CIDS-Mali. The project handles student identity information and therefore security is considered a critical requirement.

We welcome responsible disclosure of security vulnerabilities and are committed to reviewing and addressing valid security reports.

---

## Supported Versions

| Version | Supported |
|----------|-----------|
| 1.x | ✅ |
| Older Versions | ❌ |

Only the latest version is supported with security updates.

---

## Security Features

The platform is designed to protect:

- Student identity information
- Authentication credentials
- QR code verification data
- Administrative functions
- System audit records

Security controls may include:

- Password hashing
- Secure authentication
- Role-based access control
- Input validation
- Protection against SQL injection
- Protection against cross-site scripting (XSS)
- Secure session management
- Activity logging

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public issue.

Instead, report it privately by email:

**Security Contact:** Badra Aliou Sacko

**Email:** badraaliou2023@gmail.com

Please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Screenshots or evidence if applicable

---

## Response Process

After receiving a vulnerability report:

1. The report will be reviewed.
2. The vulnerability will be validated.
3. Corrective actions will be identified.
4. A fix will be developed and tested.
5. The reporter may be informed once the issue is resolved.

---

## Responsible Disclosure

Please:

- Act in good faith.
- Avoid disrupting live services.
- Avoid accessing data that does not belong to you.
- Avoid sharing vulnerabilities publicly before they are fixed.

---

## Security Best Practices for Contributors

Contributors should:

- Never commit passwords or secrets.
- Never commit API keys.
- Use environment variables for sensitive configuration.
- Review dependencies regularly.
- Keep Python packages updated.
- Follow secure coding practices.
